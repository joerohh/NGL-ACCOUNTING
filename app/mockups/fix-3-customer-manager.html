📍 What's new in Fix 3: Two changes here, both invisible until you open a customer. (1) Duplicate-code detection — typing a code that already exists shows a friendly red message under the field with a "View existing →" jump link, instead of silently overwriting or failing on Save. (2) The "Invoice" checkbox is gone from Required Documents, replaced by a static helper line. The invoice PDF is always sent automatically, so checking it as a "required doc" only ever caused false failures (this is what burned APEXMA01 + TOPTRA02 in Lorena's batch). On first run after upgrade, a one-time migration strips "invoice" out of any saved requiredDocs in Supabase + SQLite.
