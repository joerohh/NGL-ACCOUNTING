What's new on this screen

  • New Storage card under Settings — visible alongside existing cards (sign-in, notifications, selectors, backups).
  • Two storage rows: Saved merged files (your deliverables) and Temporary app files (behind-the-scenes downloads). Same 7-day cleanup rule for both.
  • Open folder button on the Saved merged files row launches Windows Explorer at your chosen location.
  • Orange callout explains the 7-day rule in plain English so there are no surprises about files disappearing.
  • Clean up now runs the 7-day sweep on demand if you want to free space immediately instead of waiting for the next startup.
  • Change output folder takes you to the existing folder-picker dialog.
  • Numbers (8.4 GB / 1.2 GB / "Last cleanup…") are placeholders. The real values are computed by the agent the first time the Settings page loads, then cached.

Where the data comes from

  • Agent exposes /storage/info → { output_size_bytes, output_file_count, downloads_size_bytes, downloads_batch_count, last_cleanup_ts, last_cleanup_freed_bytes }.
  • Sweep runs on agent startup; the "Clean up now" button calls POST /storage/cleanup.
  • Only deletes files inside Merge Outputs/ and agent/downloads/. Never touches anything else in your chosen folder.
