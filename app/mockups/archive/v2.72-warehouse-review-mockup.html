What's new on this screen

  • Warehouse filter tab added next to Import/Export, with a row count.
  • Orange "Warehouse" type badge on each row, using the NGL accent so it reads as the new type.
  • Container # and WO # cells on warehouse rows show a faint em-dash — to indicate "not applicable." Any value the exporter stuffed into those columns is ignored.
  • "Will fetch" chip reads All QBO Docs (vs. POD / BL/POL).
  • Routing summary hint updates to mention M/E/W instead of just M/E.
  • Side panel — customizable document list:
    • Each attachment has a drag handle to reorder, and an × button to remove from this merge (QBO is untouched).
    • + Add document button below the list — drop in extra PDFs that weren't on QBO.
    • Source tags tell you where each file came from: From QBO · From TMS · Added by you. The XLSX → PDF tag marks files we converted from Excel.
    • Reset link at the bottom puts the list back to what was originally fetched, undoing any reorders/removes/adds. No network call — it's a local undo only.
    • These controls apply to every row type — import, export, and warehouse — not just warehouse.
